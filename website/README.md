# AuthentIQ homepage redesign

`index.html` is the complete homepage in one self-contained file (about 50 KB). The brand font and logo
are embedded, and Montserrat loads from Google Fonts. There are no photos and almost no script
(only the sticky header and the phone booking bar).

## Deploy
Replace only `index.html` in the project Vercel currently deploys authentiqmarketing.com from.
On GitHub: open that repo → **Add file → Upload files** → drop in `index.html` → **Commit**. Vercel redeploys on its own.

Note: `mitch-kubik/authentiq-website` is the April 2026 LinkedIn-video version, not the live site.
The live site also has a Greenville studio page (`/podcast-studio-greenville-south-carolina`). The studio is
gone, so take that page down. The new homepage doesn't link to it.

## What's on the page
Seven sections: hero, what we handle, show strategy, how it works, why clients stay (stats + two
testimonials), FAQ, and a closing call to book.

- Offer: done-for-you podcast production + show strategy (new)
- Every booking button goes to Mitch's TidyCal intro call: https://tidycal.com/mitchkubik/intro-call-with-authentiq
- Brand: Messenger headline font and vector logo from the current site, brand orange / deep blue / cyan
- Brand line (from Mitch's email signature): "Podcast and short-form video producers you can trust"
- People: no photos. Mitch is named as the person on the intro call. Mitch and Bridget (producer) are named
  in the FAQ "Who will I work with?" answer. Grant isn't on the page.
- Location: the footer says "Based in New York City." There's no studio.
- Pricing and scope match the live site: production starts at $2,000/month, month-to-month;
  clips, captions and social distribution scoped on top
- Proof: 1,000+ episodes, 4–5 year client partnerships, 10-show roster cap, Charles Good and Neil Wood testimonials
