# Claude Code Sandbox

A tiny practice repo for learning the day-to-day workflow of working with
Claude Code on a real (if small) codebase: cloning, reading context files,
making edits, and shipping changes through a pull request.

## What's here

- `CLAUDE.md` — project-level instructions Claude Code reads automatically
  when working in this repo.
- `scripts/greet.py` — a tiny Python script, just so there's something to
  point at and ask questions about.
- `docs/TODO.md` — a running list of small practice tasks. This is the file
  you'll edit as part of the walkthrough.

## Why this exists

Not a real product. Just a safe place to practice the mechanics before
touching a real company repo: cloning, branching, committing, and opening a
pull request.
