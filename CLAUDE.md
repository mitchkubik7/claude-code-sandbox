# CLAUDE.md

Guidance for Claude Code when working in this repo.

## About this project

This is a practice sandbox, not a real product — there's no build system,
no tests to run, and no deploy target. Its only purpose is to give a new
Claude Code user something real to clone, read, edit, and open a pull
request against.

## Conventions

- Keep `docs/TODO.md` updated when a practice task is completed — check it
  off rather than deleting it, so the history of what was practiced stays
  visible.
- `scripts/greet.py` is intentionally trivial. Don't add real functionality
  to it; it exists only as a stand-in for "actual project code."
